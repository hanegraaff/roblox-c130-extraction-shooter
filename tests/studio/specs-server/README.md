# Server engine specs

The test project maps these specs to `ServerStorage.Tests.Studio`; the automatic server runner discovers them through TestEZ. They are absent from the release mapping.

`Foundation.spec.luau` registers shared rule cases plus server-only RoleService/RoundRules/MatchService cases through actual Instance-loaded modules. It adds repeated bootstrap start/stop ownership and the anchored/collidable GroundSpawn raycast. It temporarily renames the entrypoint status while exercising an independent runtime, then restores it.

`Map.spec.luau` registers four shared ExpandedMapRules cases plus five engine cases for P02/P13/R01/R05/R10. These first assert loaded disk/spawn/roof transforms, then exercise the real MapService against disposable Workspace clones: invalid disk dimensions; invalid anchors/counts/clearance/elevation; both approaches with a 4×6×4-stud envelope sampled every 0.5 stud and floor rays; permanent/breakable cover IDs and rays, nine protected spawn anchors and 64 perimeter sight lines (576 protected-spawn rays); authoritative containment/station exception/stop cleanup; and two pristine rebuilds restoring part names, poses and descendant counts after removal/transient content. Fixtures are destroyed even when an assertion fails.

The P07 candidate aggregate expects **137 server cases**: 54 unit, 53 integration and 30 engine cases. Collect actual structured reports, source/build and client count with zero failures/skips/errors using the [testing guide](../../../docs/testing.md). Earlier P13/P14/P05/P06 reports retain their source-specific historical counts. A passing baseline does not establish multiplayer replication, genuine late joining, actual blast protection or operated/rendered readability. The excluded server/client harnesses run after baseline suites and provide separate evidence.

`Aircraft.spec.luau` contains four P04/P14/R05/R06 engine cases against the actual AircraftService: 17 injected-time samples of canonical perimeter/altitude/tangent pose, PrimaryPart/Hitbox/muzzle attachment and collision/query contracts, initial reset and idempotent teardown; then clear/exterior/nonfinite/solid-obstructed actual world aim checks. P14 adds malformed authored height-envelope rejection and selected-muzzle obstruction/height-boundary checks. Its deterministic clock does not replace the separate real-time two-client orbit/thermal/camera harness.

`ExpandedMap.spec.luau` registers the three pure `BuildingLayout` cases and seven P13 engine cases for actual building/panel/room identities, malformed floors/stairs/markers/routes, protected lobby separation, deterministic terrain material/elevation/voxel restoration, invalid recipe no-write rejection, pristine teardown and full-orbit terrain/building sight lines. Terrain readiness waits are bounded to five seconds; surface tolerance is three studs for four-stud voxels. Actual avatar stairs and two-client/reset/late-join observations use the separate P13 harness. See the [P13 procedure](../../../docs/testing.md#run-the-p13-expanded-map-harness) and [plan record](../../../plans/13-terrain-and-buildings.md) for execution facts and remaining gaps.

`PanelDestruction.spec.luau` adds five P07 engine cases. `PanelGeometryStates` measures all 111 wall/roof/interior panels at each state, central 50% openings, preserved pivots/thickness and untouched static structure with real rays/overlaps. `PanelImpactRegistry` uses actual rays into unknown/forged-tag obstructions and registered solids to prove nonpanels consume miss outcomes without structural credit or frontier blockage; a removed Intact solid loses identity. `PreImpactCoverAndThermal` exercises both weapon profiles against pre-flush cover, residual strips and actual holes; it is ray evidence rather than rendered thermal or actual-player blast proof. `PanelFragmentPhysics` observes real gravity/static contact/server ownership, collision groups, actual solo-avatar intersection without push/health loss, query exclusion with a positive control, cap/expiration and group restoration. `PanelDestructionReset` replaces the map, rejects stale outcomes and checks repeated idempotent cleanup. The separate [P07 harness](../../../docs/testing.md#run-the-p07-destruction-harness) and operated review address traversal, actual firing/replication, late spectator and visual acceptance.

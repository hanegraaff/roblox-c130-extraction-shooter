# Server engine specs

The test project maps these specs to `ServerStorage.Tests.Studio`; the automatic server runner discovers them through TestEZ. They are absent from the release mapping.

`Foundation.spec.luau` registers shared rule cases plus server-only RoleService/RoundRules/MatchService cases through actual Instance-loaded modules. It adds repeated bootstrap start/stop ownership and the anchored/collidable GroundSpawn raycast. It temporarily renames the entrypoint status while exercising an independent runtime, then restores it.

`Map.spec.luau` registers four shared MapRules cases plus five engine cases for P02/R01/R05/R10. These first assert loaded disk/spawn/roof transforms, then exercise the real MapService against disposable Workspace clones: invalid disk dimensions; invalid anchors/counts/clearance/elevation; both approaches with a 4×6×4-stud envelope sampled every 0.5 stud and floor rays; permanent/breakable cover IDs and rays, nine protected spawn anchors and eight future perimeter sight lines; authoritative containment/station exception/stop cleanup; and two pristine rebuilds restoring part names, poses and descendant counts after removal/transient content. Fixtures are destroyed even when an assertion fails.

The current aggregate expects 57 server cases: 30 unit, 18 integration and nine foundational/map/aircraft engine cases. See [P04](../../../plans/04-aircraft-and-thermal.md) for actual candidate execution and [P03](../../../plans/03-rounds-and-roles.md) for prior round acceptance; prior P02 acceptance is recorded separately. For each new candidate, collect the actual structured report, failures/skips/errors, source/build and client count using the [testing guide](../../../docs/testing.md). Pair route clearance with focused actual walking and visual review; the current source has both, without establishing universal avatar compatibility. These baseline suites do not establish combat, destruction or multi-client round replication. The separate server/client RoundHarness drives the actual round runtime and client observations after baseline suites finish.

`Aircraft.spec.luau` adds two P04/R05/R06 engine cases against the actual AircraftService: 17 injected-time samples of canonical perimeter/altitude/tangent pose, PrimaryPart/Hitbox/muzzle attachment and collision/query contracts, initial reset and idempotent teardown; then clear/exterior/nonfinite/solid-obstructed actual world aim checks. Its deterministic clock does not replace the separate real-time two-client orbit/thermal/camera harness.

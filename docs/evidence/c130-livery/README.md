The place **C130 P17 Import** (72732833195348) reported published revision **72** at 2026-11-28 01:00:24 UTC. That predates the P28 release artifact inspected during this investigation. Studio's older local game document came from the separate `roblox-c130-p27` checkout. Its aircraft template had a primitive `Fuselage` and no P28 `Airframe` or `Propellers`. The airframe silhouette and large camouflage patches are visible there. The teeth read more clearly in the close-ups. All captures are 1787 × 1080 from Studio 0.748.0.7481526.
